# 가타카나 카드

가타카나 46자를 외우는 퀴즈 페이지입니다. 브라우저에서 바로 열립니다.

**바로 열기:** https://jihyun0326.github.io/katakana-cards/

## 문제 유형

| 문제에 나오는 것 | 답하는 방식 |
|---|---|
| 가타카나 (シ) | 영어 발음 카드 고르기 / 영어 발음·히라가나 직접 입력 |
| 영어 발음 (shi) | 가타카나 카드 고르기 / 가타카나 손으로 그리기 |

## 기능

- 46자를 두 번씩, 무작위 순서로 출제 (헷갈리는 글자 17자만, 틀린 글자만 세트도 있음)
- 헷갈리는 글자(シ·ツ, ソ·ン, ク·ケ, ヌ·ス, マ·ム, ワ·ウ·フ, チ·テ, コ·ユ)는 항상 같은 보기에 함께 출제
- 보기에 같은 행·같은 모음 글자를 섞어 짐작으로 맞히기 어렵게 구성
- 자주 틀린 글자 기록, 연속 2번 맞히면 틀린 글자 세트에서 빠짐
- 가타카나 전체 표, 다크 테마, 소리 끄기

기록은 쓰는 브라우저에 저장됩니다.
